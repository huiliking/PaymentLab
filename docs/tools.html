Tool Name Description Status Source
get_transaction_details
Get full details of a specific transaction including amount, card, email, billing/shipping address, locale, and timestamps.
Detects: Provides baseline context — amount, card, email, billing, shipping, locale, IP, device fingerprint

check_amount_anomaly
Flag unusual transaction amounts based on customer history, merchant average, and product category norms.

Get all transactions from a specific device fingerprint. Detects device reuse across multiple accounts.

Check whether browser locale, billing country, IP country, and card country are consistent. Key signal for geo fraud.

get_ip_reputation
Check IP address reputation: known proxy/VPN/Tor, datacenter IP, geographic location, historical fraud association.

Check if a human could physically travel between two transaction locations within the time gap. Uses haversine distance and realistic travel speeds.
